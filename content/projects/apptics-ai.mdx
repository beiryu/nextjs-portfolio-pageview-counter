## Technology Stack

Vite, React, TypeScript, Tailwind CSS, unframer, Framer, Motion One, Lottie, ESLint, Prettier, Husky, Vercel

## Overview

Duration: 8/2025 - 9/2025

Apptics is an all-in-one platform that turns one-time Shopify shoppers into recurring subscribers — it handles subscription management, payment optimization, and customer retention behind a single dashboard. This project is the product's public-facing site: a long-form, conversion-oriented landing experience that has to explain a fairly technical payments product to non-technical eCommerce founders, and then push them into booking a call.

The interesting part is the build pipeline. The site is designed in Framer, but instead of shipping Framer's hosted output, the design is pulled into a real codebase with **unframer** — a CLI that compiles Framer components down to plain React. The result is a normal Vite + React + TypeScript app: designers keep working in Framer and re-sync with a single command, while engineering owns the bundle, the routing, the loading strategy, and the deploy.

## Architecture

- **`npm run framer`** — the unframer CLI pulls the Framer project and generates React components into `src/framer/` (hero, features, benefits, onboarding, case studies, calculator, pricing, team, FAQ, nav, footer)
- **`src/components/`** — thin hand-written wrappers around each generated component, applying layout defaults through a shared `withDefaults()` helper, so regenerating the Framer layer never clobbers app-level overrides
- **`src/App.tsx`** — composes the sections and owns everything the design tool can't: lazy boundaries, scroll behaviour, and section anchors for the nav
- **Clean seam between design and code** — the generated directory is disposable and regenerable; all custom logic lives outside it

## Key features

- **Hero + value proposition**: "Turn Your Shoppers into Subscribers" — a single, unambiguous promise above the fold with a primary CTA
- **Feature showcase**: create & manage subscriptions, custom checkouts & upsells, and real-time revenue analytics, each with an animated in-page mockup
- **Benefits grid**: predictable recurring revenue, 2× average order value, live revenue insights, automated billing, fast setup, and failed-payment recovery — driven by a Lottie animation
- **Comparison table**: Apptics vs. competitors across ~20 capabilities (chargeback mitigation, MID management & routing, multi-currency, decline salvage AI, fraud prevention, PCI tokenization, plan A/B testing)
- **4-step onboarding walkthrough**: connect your business → unlock your growth strategy → turn clicks into cash → grow on autopilot
- **Interactive ROI calculator**: prospects estimate their potential MRR from passive subscriber income before they ever talk to sales
- **Social proof**: founder and CEO testimonials from brands that scaled with the platform
- **Pricing tiers**: 30-day free trial, a one-time-fee Pro plan, and custom Enterprise pricing, with feature breakdowns per tier
- **Team & FAQ sections**: named team profiles plus curated answers to the objections that block signup (cost, compliance, supported niches, differentiation)

## Performance Engineering

This is where owning the code pays for itself — a hosted design-tool export gives you none of it:

- **Route-level code splitting**: every section below the fold is a `React.lazy()` import, so the initial bundle carries only the nav and the hero
- **Custom `LazyLoad` component**: an `IntersectionObserver` with a 300px `rootMargin` mounts each section just before it scrolls into view, with a `Suspense` placeholder holding the layout so nothing shifts
- **Self-hosted fonts**: Plus Jakarta Sans and Fontshare faces vendored into the repo and served from the same origin, removing a third-party round trip on the critical path
- **Static build on Vercel's edge network** — a Vite production build served as immutable, fingerprinted assets

## Design & User Experience

- **Scroll-driven narrative**: sections are ordered as a funnel — problem, product, proof, price — so the page reads as one continuous pitch rather than a set of disconnected blocks
- **Motion as explanation**: dashboard mockups, revenue charts, and checkout flows animate on scroll (Motion One) to show the product working instead of describing it
- **Design tokens**: a small, consistent palette (indigo primary, cyan and lilac accents on near-white surfaces) carried over from Framer's token system
- **Responsive breakpoints**: purpose-built layouts for desktop (1200px and up), tablet (810–1199px), and mobile (under 810px) rather than a single fluid layout that degrades
- **Repeated conversion points**: "Book a Call" and "Calculate My MRR" CTAs recur at every scroll depth so intent is never more than one screen from an action

## Code Quality

- TypeScript throughout the application layer
- ESLint 9 with the React, React Hooks, JSX a11y, and Prettier plugin sets
- Husky and lint-staged running format and lint checks on every commit
- Prettier as the single formatting authority across TS, JSX, CSS, JSON, and Markdown

This project shows how to get the best of both worlds on a marketing site: the iteration speed of a visual design tool, and the performance, tooling, and code quality guarantees of a real front-end codebase — with a regeneration step that keeps the two in sync instead of drifting apart.
