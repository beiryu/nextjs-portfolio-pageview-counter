## 📚 **Technology Stack**

NextJs, TypeScript, TailwindCSS, Vercel

## 📃 **Overview**

Duration: 4/2024 - now

A modern, feature-rich online course platform built with Next.js, Prisma, and TypeScript. This platform allows creators to build and publish courses while providing users with an intuitive learning experience.

## 🚀 **Key features**

- Course creation and management for instructors
- Intuitive learning interface for students
- Progress tracking and analytics
- Responsive design using Tailwind CSS
- User authentication and authorization
- Content management system for course materials
